# Agenda de Contactos

Programa en Python que utiliza una **colección de datos (diccionario)** para resolver un problema sencillo de la vida real: guardar y administrar contactos con su nombre y número telefónico.

## Autor
**Jeremy Escobar**

## Descripción

Este programa permite:
- Agregar contactos a la agenda.
- Mostrar todos los contactos guardados.
- Buscar un contacto por nombre.
- Eliminar un contacto de la agenda.

La información se almacena en un **diccionario**, donde la clave es el nombre del contacto y el valor es su número telefónico.

## Cómo ejecutarlo

1. Asegúrate de tener Python instalado (versión 3.x).
2. Descarga el archivo `agenda_contactos.py`.
3. Ejecuta el programa desde la terminal:

```bash
python agenda_contactos.py
```

4. Usa el menú en pantalla para elegir una opción:

```
===== AGENDA DE CONTACTOS =====
1. Agregar contacto
2. Mostrar contactos
3. Buscar contacto
4. Eliminar contacto
5. Salir
```

## Estructura de datos utilizada

- **Diccionario (`dict`)**: almacena pares `nombre: teléfono`, permitiendo acceso rápido por clave.

## Tecnologías

- Python 3
